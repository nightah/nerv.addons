# Kayo Sports for Kodi

`plugin.video.kayo` plays your own Kayo Sports subscription in Kodi.

- **Live channels:** Fox Footy, Fox League, Fox Cricket, ESPN and the rest of Kayo's linear channels
- **Live events, replays, minis, and shows**
- **Search** across the Kayo catalogue
- **Live TV and guide** in Kodi's TV section through IPTV Merge

Kayo now runs on DAZN's platform, so the addon talks to DAZN's APIs (`*.indazn.com`) using the Kayo brand. It is built on SlyGuy's common module (`script.module.slyguy`), which handles Widevine CDM installation, InputStream Adaptive setup, the local stream proxy, settings, and bookmarks.

## Requirements

- Kodi 20 or newer (InputStream Adaptive `stream_params` support is required)
- An active Kayo subscription and an Australian connection

## Install

Install the [NERV Repository](../README.md#install), then **Add-ons → Install from repository → NERV Repository → Video add-ons → Kayo Sports**. Kodi then keeps the addon updated.

Open the addon, choose **Login**, and enter your Kayo email and password. Only the session token is stored; the password is not saved.

<details>
<summary>Installing from a zip instead</summary>

Download `plugin.video.kayo-<version>.zip` from [GitHub releases](https://github.com/nightah/nerv.addons/releases?q=plugin.video.kayo&expanded=true) and use **Add-ons → Install from zip file**. This gets no automatic updates, and Kodi still needs the NERV Repository (or the [SlyGuy repository](https://www.matthuisman.nz/2020/02/slyguy-kodi-repository.html)) installed to fetch the `script.module.slyguy` dependency.

</details>

## Live TV and guide

The addon supports SlyGuy's IPTV Merge (`plugin.program.iptv.merge`, listed in the NERV Repository via SlyGuy's feed). IPTV Merge reads the addon's channel playlist and configures PVR IPTV Simple Client for you. Channels are grouped under the addon name (rename the group in IPTV Merge's playlist settings if you like) and numbered as on Foxtel:

| Number | Channel |
| ---: | --- |
| 500 | Fox Sports News |
| 501 | Fox Cricket |
| 502 | Fox League |
| 503 | Fox Sports 503 |
| 504 | Fox Footy |
| 505 | Fox Sports 505 |
| 506 | Fox Sports 506 |
| 507 | Fox Sports 507 |
| 509 | ESPN |
| 510 | ESPN2 |
| 529 | Racing.com |

The TV guide is generated by the addon from the schedule Kayo includes with its live channel list (now, next, and about 2.5 days ahead), so IPTV Merge lists it as the **Kayo Sports** add-on source and refreshes it on each merge.

## Testing outside Kodi

`tests/smoke.py` runs the addon's real `api.py` against the live services, with small shims standing in for the SlyGuy modules.

```bash
python3 -m pip install requests
python3 plugin.video.kayo/tests/smoke.py --login
```

Without `--login` it only checks the public catalogue. With `--login` it prompts for your credentials, then checks:

- token refresh and Playback
- the manifest, and segment access with and without the CDN token
- licence endpoint reachability
- lock refresh and release

The token is cached in `plugin.video.kayo/tests/.userdata.json` (git-ignored, mode 600).
